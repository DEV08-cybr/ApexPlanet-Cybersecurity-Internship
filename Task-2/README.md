# Task-2: Network Security & Scanning

## Overview
Covering reconnaissance, port scanning, vulnerability assessment, packet analysis, and basic firewall configuration.

## 1. Reconnaissance & Port Scanning
* **Active Recon (Nmap):** Scanned target systems for open ports, service versions, and OS fingerprinting.
* **Commands Used:** 
  - \
map -sS -sV -O <target-ip>\

## 2. Vulnerability Scanning
* Configured and executed scans using Nessus Essentials / OpenVAS against Metasploitable2.
* Categorized findings into Critical, High, Medium, and Low risks.

## 3. Packet Analysis & Firewall Rules
* Captured and filtered traffic using Wireshark.
* Configured \iptables\ to block unwanted traffic and port scans.
